🏫 Madrasa & Institutional Result Management System

## 📌 Project Overview
A comprehensive institutional result management web application built to generate printable marksheets, merit rankings, and handle custom grading rules (General & Befak grading modes).

## 🛠️ Technologies Used & Why?
* **HTML5 & Modern CSS:** For structured institutional forms and report layouts.
* **JavaScript:** For automating GPA calculations, sorting merit positions, and rendering dynamic marksheets.

---

## ✨ Key Features
* ✅ Student Result Entry & Subject-wise Marks Management
* ✅ Automated GPA & Grade Calculation (General & Befak Modes)
* ✅ Printable Marksheets & Merit List Generation
* ✅ User-friendly Dashboard for Administrators and Teachers
